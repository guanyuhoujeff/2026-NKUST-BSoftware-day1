# Lab 3 天花板與地板

用 Lab 1 的 `bias` 算出每一天的乖離率，依 CMoney「權證小哥－地板天花板反轉價位監控表」官方公開規則，從過去 5 年找出天花板（正乖離的第 95%）和地板（負乖離的第 5%），換回價格畫在 K 線上，判斷今天的位置，最後匯出 CSV 帶回家。

## 怎麼開始

1. 從上一層 README 的 **Open in Colab** 按鈕打開，先「檔案 → 在雲端硬碟中儲存複本」
2. **第一格一定要最先跑**：它會把套件裝成講義用的版本
3. 最後一步會下載一個 CSV 檔，Colab 關掉後檔案會消失，請存到自己的電腦

## 檔案

| 檔案 | 用途 |
|---|---|
| `Lab3_天花板與地板_教學版.ipynb` | 上課用，關鍵程式碼留空讓你填 |
| `Lab3_天花板與地板_完整版.ipynb` | 回家複習用，全部答案與執行結果 |

## 注意

- 天花板、地板用「過去 5 年」算，每天執行的數字都會差一點。
- 天花板和地板是用同一段歷史定義出來的，不保證明天會反彈。
