# Lab 2 抓真資料、算均線、畫 K 線

用 yfinance 抓台積電（2330）5 年日資料，刪掉休市日的假資料，算出 5 日、20 日均線（10/30 的 5 日均線 2399.0，跟 Lab 1 手算的一樣），再用 plotly 畫紅漲綠跌的 K 線圖。

## 怎麼開始

1. 從上一層 README 的 **Open in Colab** 按鈕打開，先「檔案 → 在雲端硬碟中儲存複本」
2. **第一格一定要最先跑**：它會把套件裝成講義用的版本

## 檔案

| 檔案 | 用途 |
|---|---|
| `Lab2_抓真資料畫K線_教學版.ipynb` | 上課用，關鍵程式碼留空讓你填 |
| `Lab2_抓真資料畫K線_完整版.ipynb` | 回家複習用，全部答案與執行結果 |

## 注意

- 資料抓到你執行的那一天，筆數、最後幾天的價格會跟完整版不同；10/30 以前的數字不會變。
- 盤中執行會抓到還沒收盤的價格。

## 資料來源

Yahoo 財經（yfinance），2330.TW，當天實際成交價（`auto_adjust=False`）。
